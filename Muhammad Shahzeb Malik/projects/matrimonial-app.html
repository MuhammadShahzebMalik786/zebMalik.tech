Project Overview

NikahMatch is a modern, culturally attuned matrimonial and matchmaking mobile application designed to connect serious marriage-seekers and families in a respectful, safe, and privacy-conscious environment. Built from the ground up using Flutter for seamless cross-platform performance across iOS and Android, backed by scalable cloud infrastructure.

Technology Stack

Flutter Dart Firebase Auth Cloud Firestore Firebase Cloud Messaging Cloud Functions End-to-End Encryption Figma UI/UX

Key Features & Capabilities

  • Multi-Step Biodata Profile Builder: Comprehensive profiles covering education, profession, family background, lifestyle, religious values, and marriage expectations.
  • Discrete Photo Privacy & Blur Modes: Users control who sees their photos with timed blur toggles, watermarks, and on-demand unlock requests to prevent unauthorized copying.
  • Compatibility & Preference Matching: Intelligent filtering based on age, location, education, caste/ethnicity, religiosity, and lifestyle preferences.
  • Wali & Family Chaperone Mode: Optional inclusion of guardians or family members in chats for cultural peace of mind.
  • Real-Time Secure Chat: End-to-end encrypted messaging with typing indicators, read receipts, and voice note support.
  • Identity Verification & Anti-Spam: Phone number OTP verification and report/block controls for high-trust user safety.
  • Instant Push Notifications: Real-time alerts for interest requests, profile views, and new messages.
